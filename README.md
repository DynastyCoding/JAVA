## Practice Topics

- **Syntax**    : variables, control flow, arrays, methods
- **OOP**       : encapsulation, inheritance, polymorphism, abstraction, interface
- **Collections**       : ArrayList, HashMap, HashSet
- **Exception Handling**: try-catch, throw, throws, finally, custom exceptions
- **Stream & Lambda**   : filter, map, toList, method reference
- **String**    : equals, contains, trim, split, replace, substring, charAt, indexOf


## 開發習慣

- 命名遵循大駝峰、小駝峰、常數全大寫
- 邊界處理與無效輸入防護
- 邏輯與輸出分離
- 變數命名以業務意義優先
